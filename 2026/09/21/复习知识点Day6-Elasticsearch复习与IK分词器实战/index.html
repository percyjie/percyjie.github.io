一句话记住今天：ES = 分布式搜索引擎 = 倒排索引 + 分片副本 + RESTful API。面试抓四段：① 概念（文档 / 索引 / 分片 / 副本 / 倒排索引）；② 中文分词（ik_smart 与 ik_max_word：索引用细、搜索用粗）；③ 查询 DSL（match 分词匹配、term 精确匹配、bool 组合、聚合）；④ 运维细节（近实时写入、深分页、脑裂、reindex）。

1. ES 是什么：一句话 + 一张表看懂

MySQL 类比 Elasticsearch 说明
Database Index（索引） 一类数据的集合
Table Type（7.x 废弃） 8.x 一个索引只一种”表”
Row Document（文档） 最小数据单元，JSON
Column Field（字段） 文档里的属性，有类型
索引 倒排索引 词 → 文档列表，搜索快的根本
  • Index：一类文档的集合，含 mapping（字段类型）+ settings（分片/副本数）。
  • Shard 分片：数据水平切分的最小存储单元，建索引后主分片数不可改，只能 reindex。
  • Replica 副本：主分片的备份，高可用 + 读扩展（读可走副本）。
  • Document：一行数据，JSON 序列化存储。

面试开场白：”ES 把文档分词后建倒排索引，用 Term→Doc 的映射做到毫秒级全文检索；配合分片副本把数据分布到多台机器，获得容量与高可用。”

2. 倒排索引与写入链路（原理核心）

正排：文档 → 词（遍历文档找词）。
倒排：词 → 文档（搜索时直接按词找文档，近乎哈希查表）。

分词（Analyze）三阶段：

  • 默认 standard 分词器对中文是按单个汉字切：搜”复习”能中，但”复习ES”这种连续业务词会碎，召回差 → 中文必须上 IK。
  • 写入链路：请求 → 主分片 → 写内存 buffer + translog → 默认 1s 自动 refresh 生成 segment（可被搜索，所以 ES 是”近实时”）→ 后台 flush 落盘并清 translog。
  • 读链路：查询 → 分词 → 拿 Term 查倒排 → 合并各分片结果打分 → 返回 Top N。

3. IK 分词器使用（今天重头戏）

3.1 为什么是 IK

IK 内置词典 + 语法扩展，按词典最大匹配 + 词库切中文，而不是按字切：

模式 行为 用途
ik_smart 粗粒度、尽量少切 搜索时用：命中更准、噪声小
ik_max_word 细粒度、穷举所有切分 索引时用：召回更全

口诀：索引 ik_max_word（多切分多召回），搜索 ik_smart（减少误命）。

4. 查询 DSL 速查（面试手写水平）

查询 行为 场景
match 分词后匹配（默认多词 OR） 全文搜索
term 不分词精确匹配 keyword 精确值
terms 多个精确值 IN status: [1,2,3]
range 范围（gt / gte / lt / lte） 价格、日期区间
bool should / must / must_not / filter 组合 复杂业务查询
match_phrase 词组保持顺序 “订单取消” 连续语

两个关键点（面试必背）：

  1. filter 不参与评分、可被缓存；must 参与评分（相关度排序）。
  2. term 对 text 字段几乎总是失效（term 是完整词，而 text 已被分词成小块），精确匹配请用 keyword 字段或加 .keyword 子字段。

5. 使用注意点与线上排查

问题 解法
中文搜不到 / 被拆碎 检查的是 IK 分词器；_analyze 验证；mapping 重建
term 查不到 字段必须是 keyword；text 需 title.keyword
深分页超 10000 默认 from+size 上限 10000 → search_after + PIT（游标）
加了新字段但索引报错 mapping 不支持直接改已有字段类型，需 reindex 重建
分片数不合适 主分片建索引后改不了 → 新索引 + _reindex 热迁移
写入慢 调 refresh_interval、批量 bulk、临时关副本；本质是减少 segment 与磁盘 IO
索引数量爆炸 每个分片 30~50GB 峰值经验值，太多小的分片反而增加路由开销

6. 常见面试题（背这组）

面试题 一句话答案
倒排索引原理？ Term → Doc 列表，先分词再查，搜索变查表
为什么 ES 检索快？ 倒排索引内存化 + 分片并行 + 过滤缓存
中文为什么要用 IK？ standard 按字切，中文需要词典/语法分词
ik_smart 与 ik_max_word？ 粗切 vs 细切：索引 max、搜索 smart
自定义词典怎么加？ IKAnalyzer.cfg.xml 配 ext_dict，可用 remote_ext_dict 热更新
match vs term？ match 分词后匹配 text；term 精确匹配 keyword
bool 的 filter 与 must？ 都要求命中，filter 不算分可缓存
为什么”近实时”？ 默认 1s refresh 生成 segment 才能被搜
translog 作用？ 崩溃恢复；flush 落盘后清空
脑裂怎么规避？ 配置 minimum_master_nodes = 候选 master 数 / 2 + 1，防多主分裂
分页超 10000 怎么办？ search_after + PIT，大游标页
主分片为什么不能改？ 路由 = hash(doc id)%分片数，改后数据错位 → 重索引迁移

7. 自测三问

  1. 线上中文搜索”布隆过滤器”搜不到，第一反应查什么？用什么 API 验证分词结果？
  2. term 查询为什么在 text 字段上经常查不到？正确姿势是什么？
  3. 主分片数想从 3 加到 5，直接改不了——给出完整迁移步骤（新索引 → mapping → reindex → 切别名）。
